Abstract: Current deep learning-based object detection for Synthetic Aperture Radar (SAR) imagery mainly adopts optical image methods, treating targets as texture patches while ignoring inherent electromagnetic scattering mechanisms. Though scattering points have been studied to boost detection performance, most methods still rely on amplitude-based statistical models. Some approaches introduce frequency-domain information for scattering center extraction, but they suffer from high computation cost and poor compatibility with diverse datasets. Thus, effectively embedding scattering topological information into modern detection frameworks remains challenging. To solve these problems, this paper proposes the Physics-Aware Scattering Topology Embedding Framework (PASTE), a novel closed-loop architecture for comprehensive scattering prior integration. By building the full pipeline from topology generation, injection to joint supervision, PASTE elegantly integrates scattering physics into modern SAR detectors. Specifically, it designs a scattering keypoint generation and automatic annotation scheme based on the Attributed Scattering Center (ASC) model to produce scalable and physically consistent priors. A scattering topology injection module guides multi-scale feature learning, and a scattering prior supervision strategy constrains network optimization by aligning predictions with scattering center distributions. Experiments on real datasets show that PASTE is compatible with various detectors and brings relative mAP gains of 2.9% to 11.3% over baselines with acceptable computation overhead. Visualization of scattering maps verifies that PASTE successfully embeds scattering topological priors into feature space, clearly distinguishing target and background scattering regions, thus providing strong interpretability for results.

Task and scene: 任务：全天候（around-the-clock）目标检测，即昼夜场景下的目标检测。应用场景：无人机（UAV）航拍遥感图像。传感器/模态：红外（infrared）与可见光（visible）双模态融合。目标类别：无人机车辆数据集（drone vehicle dataset）中的车辆目标。检测形式：旋转框（rotating/oriented bounding box）检测，保留目标朝向信息。

Model architecture: YOLOFIV基于YOLO框架改进，核心设计包括：(1) 基于注意力机制的双流骨干网络（dual-stream backbone），分别提取红外和可见光两种模态特征；(2) 特征增强网络（feature enhancement network）中集成ECA（Efficient Channel Attention）注意力机制，增强对困难检测场景的关注；(3) 将水平检测头（horizontal detection head）改进为旋转检测头（rotating head）以保留目标朝向。整体属于双模态特征融合的目标检测架构。

Lightweight method: 轻量化主要体现在架构层面的参数效率设计：双流骨干网络与ECA注意力机制的组合在保持精度的同时大幅压缩参数量。摘要明确报告相对基线双模态模型（UACMD）参数量减少92.35%，推理速度提升17.87倍。摘要未提及剪枝、量化、知识蒸馏或NAS等具体压缩技术，也未报告FLOPs、内存占用或能耗数据。

Onboard deployability: 摘要报告了参数量减少92.35%和17.87倍推理加速，表明模型具有较好的计算效率潜力，这对星上/机载部署有利。但摘要未报告具体参数量数值、FLOPs、延迟（毫秒级）、内存占用、能耗或任何边缘硬件（FPGA/NPU/嵌入式GPU）上的实测部署结果，也未涉及在轨（in-orbit）推理场景。因此部署证据不完整，仅能确认其相对效率优势。

Datasets and metrics: 数据集：广泛使用的无人机车辆数据集（drone vehicle dataset，摘要未给出具体数据集名称，如DroneVehicle或类似）。指标：mAP@0.5（mean average precision at IoU 0.5）。实验设置：与基线双模态模型对比，以及与UACMD（专为ARSI即航拍遥感图像目标检测设计的方法）对比。

Experiments: 主要结果：(1) YOLOFIV在无人机车辆数据集上达到64.71%的mAP@0.5；(2) 相比基线双模态模型精度提升8.32%；(3) 与UACMD精度相当，但参数量减少92.35%，推理速度提升17.87倍。摘要未报告消融实验细节、各模态单独性能、不同场景（白天/夜间）的分项精度，也未报告与其他主流检测器的对比。

Abstract: With the rapid advancements in deep learning technology, various deep learning-based object detection algorithms have found extensive applications in UAV-related tasks. However, motivated by the fact that current object detection algorithms for unimodal aerial remote sensing images fail to achieve around-the-clock object detection. To tackle this, we propose an around-the-clock object detection algorithm YOLOFIV that fuses infrared and visible features. First, we design a dual-stream backbone network based on the attention mechanism to adequately extract the features of both modalities. Moreover, the ECA attention mechanism is integrated into the feature enhancement network to amplify attention toward challenging detection scenarios. Finally, we improve the horizontal detection head to a rotating one to preserve object orientation. We evaluate the proposed method YOLOFIV on the widely used drone vehicle dataset, YOLOFIV achieves an accuracy of 64.71% (in terms of$\text{mean average precision}_{0.5}$), accuracy improvement of 8.32% over baseline bimodal model, similar performance to UACMD designed for ARSI object detection but with 92.35% reduction in parameter count, and 17.87 times speedup. The results show that our approach achieves round-the-clock object detection while maintaining a favorable accuracy-speed tradeoff.
